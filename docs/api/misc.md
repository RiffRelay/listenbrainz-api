# Miscellaneous and history export routes

## Miscellaneous

- `/1/explore/fresh-releases/`
- `/1/explore/color/{color}`
- `/1/explore/lb-radio`
- `/1/status/get-dump-info`

## User history exports

- `/1/export/`
- `/1/export/list`
- `/1/export/{export_id}`
- `/1/export/{export_id}/download`
- `/1/export/{export_id}/delete`

Exports require account authentication. Export creation can be asynchronous;
follow the job status before downloading.
